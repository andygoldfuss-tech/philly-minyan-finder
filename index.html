For the first version, enter your regular shuls or import a JSON schedule. Daily recurring times only; variable zmanim-based times must be checked manually.

Import expects an array of objects with name, area, type, time (HH:MM), days, and optional url. Import replaces your current minyan list.

Schedules and checkmarks are stored only in this browser. Published starter listings are included; no GoDaven data is collected. Zmanim calculations, automatic updates, location sorting and cloud sync are planned features, not yet implemented.
